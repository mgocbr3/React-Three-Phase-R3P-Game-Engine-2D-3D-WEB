# @pixlland/engine-core

Shared TypeScript core for PixlPlayground. Pure code; no React, no Three, no
Phaser. The CLI (`@pixlland/engine-cli`), the editor (`pixlplaygroundstudio`)
and the future MCP server import from here.

## What lives here

- **`.pixl` package** — pack/unpack a project folder into a single ZIP with a
  hashed manifest. See [`pixlPackage.ts`](./src/pixlPackage.ts).
- **Asset source duality** — read assets either from a URL (dev server) or a
  `FileSystemDirectoryHandle` (OPFS-unpacked `.pixl`), via a uniform
  `AssetSource` interface. Adapted from
  [WesUnwin/three-game-engine](https://github.com/WesUnwin/three-game-engine)
  (MIT). See [`assetSource.ts`](./src/assetSource.ts).
- **Manifest schema** — [`manifest.ts`](./src/manifest.ts).
- **Content hashing** — SHA-256 via the platform's `SubtleCrypto`. See
  [`contentHash.ts`](./src/contentHash.ts).
- **Node helpers** — `readProjectFolder` / `writeProjectFolder` live in
  [`nodeProjectIO.ts`](./src/nodeProjectIO.ts) so browser bundles can drop
  `node:fs` / `node:path`.

## .pixl format (v1)

A `.pixl` file is a standard ZIP (Deflate, no encryption) with this layout:

```
my-game.pixl
├── manifest.pixl.json          # generated by the packer (format, hashes, runtime)
├── project.pixlproject.json    # the project document (schema v2)
├── Assets/                     # 3D_Models, Sprites, Textures, Audio, …
├── Scenes/                     # *.pixlscene.json
├── Scripts/                    # *.pixlscript.js
└── ProjectSettings/            # build.json, input.json, audio.json
```

Two packs of the same project bytes produce **byte-identical** `.pixl`
output: `mtime` is pinned to `project.createdAt`, file order is sorted by
path, and the content hash covers `path + size + sha256` of every entry.
